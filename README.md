# 건국대학교 메이커스페이스 센터 웹 플랫폼 (KU MakerSpace Portal)

건국대학교 메이커스페이스 센터의 일일 운영을 보조하고, 내부 스태프 및 근로장학생의 표준 운영 절차(SOP)를 체계적으로 안내하기 위한 웹 애플리케이션입니다. Vercel 배포에 최적화되어 있습니다.

## 📌 주요 기능

- **출근 & 오픈 점검 매뉴얼 (SOP)**: 단계별(Step 1 ~ N) 순차 가이드 및 사진 1:1 매칭
- **A4 PDF 저장 및 인쇄 지원**: 브라우저 인쇄(`window.print()`)를 통해 공식 결재 서식으로 깔끔하게 출력
- **스태프 체크리스트**: 실시간 진행률(0% ~ 100%) 및 로컬스토리지 자동 저장
- **사진 뷰어 & 라이트박스**: `public/manual/OpeningManual_{id}.jpg` 연동 및 클릭 시 고화질 확대
- **KU 시그니처 테마**: 건국대 상징 컬러(KU Forest Green `#004D25`) 기반 인터페이스

## 📖 개발 컨텍스트 및 상세 문서

상세 기획, 컴포넌트 아키텍처, 파일 구조, 개발 이력 등은 [DEV_CONTEXT.md](./DEV_CONTEXT.md) 파일에 영구 기록되어 지속적으로 관리됩니다.

## 🚀 실행 방법

```bash
# 패키지 설치
npm install

# 로컬 개발 서버 실행
npm run dev

# 프로덕션 빌드 검증
npm run build
```

브라우저에서 `http://localhost:3000`으로 접속하여 확인할 수 있습니다.
